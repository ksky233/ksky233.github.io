CORE USE CASES · FROM INPUT TO EVIDENCE

两条从输入到结果的工程链路。

分别覆盖知识证据获取与企业工具治理，构成 Agent 基础设施的两个互补方向。

01 / DUALSTRUCT结构化文档检索
  1. 01文档接入

    PDF 与解析任务进入受控 Ingestion 流程。

  2. 02稳定结构

    Parser 输出归一化为 Stable DualStruct IR。

  3. 03双路索引

    RetrievalUnit 映射 Dense 与 Sparse View。

  4. 04检索精排

    Hybrid Retrieval、RRF 与 Reranker 组合。

  5. 05证据回答

    构造 Context，并返回可定位的 Citation。

02 / NEXUSMCP企业工具治理
  1. 01接入上游

    注册企业 HTTP Service 与 OpenAPI 来源。

  2. 02导入审核

    解析 Operation、标准化 Schema 并 Review。

  3. 03发布工具

    原子发布 ToolVersion 与 ToolBinding。

  4. 04发现治理

    FTS/Hybrid Search 后执行 Policy 与 Credential。

  5. 05执行审计

    调用 Upstream，并记录 Retry、Execution 与 Audit。
